**Subject:** Does publishing derived 1-second book snapshots from XNAS.ITCH count as redistribution?

Hi,

I have a historical XNAS.ITCH MBO subscription and I would like to check
whether a specific use is permitted before I publish anything.

I have built an open-source order book reconstruction and backtesting
project that I would like to put on GitHub as a portfolio piece. It is
non-commercial and not a product. I want to include a small sample dataset
so the accompanying dashboard renders for anyone who clones the repo,
without them needing a Databento account.

What I would like to publish is derived, not raw:

- One symbol (AAPL), one session (2026-07-30), pulled roughly a month ago,
  so nothing is within 24 hours of receipt.
- Reconstructed top-of-book state sampled once per second: for each side,
  the top 5 price levels with aggregate size and order count. Roughly
  610,000 rows.
- No raw MBO messages, no order IDs, no per-order records, and no
  nanosecond timestamps. The original feed cannot be reconstructed from it.
- Alongside it, simulated fills and summary statistics generated by my own
  backtest, which are my output rather than your data.

My questions:

1. Does publishing that derived, downsampled, month-old snapshot series in
   a public repository count as redistribution under my agreement?
2. If it does, is there a de minimis or delayed-data allowance that would
   cover a sample of this size and age, or would it require a formal
   Nasdaq license or ILA?
3. If the answer is no for XNAS.ITCH, is there a dataset you would suggest
   instead for a publicly shareable sample of this kind?

To be clear about the alternative: I have a synthetic data generator that
produces a schema-identical day, and I am currently shipping that in the
public repo instead. So this is not blocking me. I would simply rather
publish something real if it is permitted, and I would rather ask than
assume.

Happy to share the repository or the exact file if that helps.
